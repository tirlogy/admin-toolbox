Tools for IT admins

Check mail security, DNS and networks right in the browser. No account, no server, input stays local.

  • Mail domain checkMX, SPF with lookup count, DKIM, DMARC, BIMI, MTA-STS and TLS-RPT with traffic lights and suggestions.
  • Header analysisRoute as a timeline, SPF/DKIM/DMARC results, spam hints and suspicious mismatches.
  • Subnet calculatorIPv4 and IPv6, splitting, summarizing and IP-in-network check.
  • DNS diffZone file from before against live DNS. Ideal for DNS migrations.
  • HelpersPasswords, JWT, Base64/URL/hex, hashes and certificates. Works offline.

Only the mail domain check and DNS diff send DNS queries to Cloudflare DNS (fallback Google Public DNS). Everything else runs offline.
